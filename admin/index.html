One-time setup: connect to GitHub

This page needs a GitHub access key so it can save campaigns to your repo. You create the key once — it stays only in this browser.

  1. Open github.com → new fine-grained token (log in as michaello-TS)
  2. Token name: "QR panel" · Expiration: pick Custom and set it ~1 year out
  3. Repository access: "Only select repositories" → choose Qr_code
  4. Permissions → Repository permissions → Contents: set to Read and write
  5. Click Generate token, copy it, and paste it below

Open on another device / share with a colleague

This makes a special link with your key hidden inside — open it once on any device (or send it to a trusted colleague) and that browser is connected, no typing needed.

Treat the link like a key to the office: anyone who has it can change where your QR codes point. Share it only in private (AirDrop / password manager), and if it ever leaks, delete the "QR panel" token on GitHub to lock everyone out.
